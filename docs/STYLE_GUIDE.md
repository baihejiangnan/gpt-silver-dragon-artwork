# GPT白银龙娘 · 角色与风格提示词

## 视觉基准

四张独立图位于 `assets/character/`。脸部图负责身份，正面负责服装与总体比例，左侧及背面负责角、翼、尾与发饰位置。原始参考图为 `reference.png`，完整资产卡为 `character-sheet-v1.png`。

固定特征：成年女性龙娘；银白长发、紫瞳、尖耳、两支带节纹的银白龙角；一对白银骨架与淡紫翼膜的龙翼；一条银白叠鳞长尾。白银高领长礼服、银色结环及链饰、层叠长袖和高跟鞋。角色**自身左侧**佩戴结环发饰及长流苏，正面看在画面右侧，背面看在画面左侧。背面为散发。

保持温和、专注、好奇的气质，可带一点银龙的骄傲。不要为强化龙的特征，把手画成怪兽手；纤细人手和半透明龙爪虚影应当可以分别识别。

## 通用角色提示词

```text
根据附带的脸部、正面、左侧与背面参考图，绘制同一位成年白银龙娘。
保持银白长发、紫瞳、节纹银白双角、尖耳、淡紫龙翼与一条银白叠鳞尾，
保持白银高领长礼服、银色结环饰物、链饰、长袖和鞋的造型关系。
发饰与长流苏固定在角色自身左侧；不要因改变朝向而换到另一侧。
脸部身份保持一致，使用干净柔细的日系动漫线稿与明确的明暗层次。
此次场景和动作：[填写]。
只改变：[填写]；保持不变：[填写]。
无文字、无水印，不添加其他人物。
```

若只画鳞片、龙尾或物件，优先附相应局部参考，明确“不出现人物头部与躯干”。把完整人物图作为唯一参考可能让模型自动补出半身像。

## 卡牌插画提示词

```text
制作一张卡牌技能插画，横向4:3，单一连续画面，不含卡框、牌名、数字或技能文字。
本张的唯一主要对象：[尾部／手与龙爪虚影／鳞盾／翼膜／角／书页等]。
动作：[填写起点、运动方向、命中点]。
技能关系：[例如已有格挡转为冲击、烧去一页并形成护盾]。
采用白银龙娘的银白材质与紫色能量，背景用较暗的石色、靛蓝或灰紫衬托主体。
轮廓清晰，在缩小为卡图时仍能辨认主要动作。减少装饰碎屑和细小符文。
本张人物露出范围：[只露尾部／只露手与袖口／少量侧脸等]。
不为了展示身份而补出完整上半身；若无人物出场需求，不画脸。
白色高光保留鳞片细节，紫色能量不要遮住手指、尾尖和动作命中点。
无新增角色，无拼图和多宫格。
```

构图尽量一张只说明一个主要动作。攻击可以锐利、快速；格挡更强调屏障与受力；抽牌、回收、升级与消耗通过书页位置、重绘纹路或燃尽关系表达，不必全用爆炸光效。

## GPT特点如何落到已有机制

| GPT主题 | 画面表达 | 对应已有机制 |
| --- | --- | --- |
| 递归与重复输出 | 回环火焰、同形余影 | 愤怒的复制入弃牌堆 |
| 信息衔接 | 掌击后翻出下一页 | 剑柄打击的攻击与抽牌 |
| 预演 | 虚实分明的后续轨迹 | 预备打击的本回合力量 |
| 校准 | 重新描绘鳞纹符卡 | 武装的手牌升级 |
| 整理信息 | 焚页、归位顶页 | 消耗与牌堆回收 |
| 集成已有经验 | 多种小攻击符印汇入主冲击 | 按打击牌数量增加伤害 |

这些是主题对应，不增加“上下文点数”“推理值”等新资源。卡牌数值与标签仍由数据和规则确定，不靠画中符文数量暗示新效果。

## 第一轮需要重点观察

当前图组使用较强的银白高光和紫色能量。后续可以测试减少泛光与石屑、拉开背景明度，以及进一步降低部分牌的人物占比。它们是可讨论的改图方向，不表示当前所有插画已被用户最终选用。
