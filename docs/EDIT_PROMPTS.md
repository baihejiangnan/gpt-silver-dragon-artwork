# 可直接使用的辅助修改提示词

先附上需要修改的**独立插画原图**，再附必要的人物或材质参考。不要把完整卡面当作唯一输入去让模型重写牌名和数值；卡框与技能文字通过排版脚本生成。

把方括号内的内容替换成自己的选择。每次尽量只改一个重点，保留原图并另存 `v2`、`v3`，便于对照。

## 1. 通用定向改图

```text
输入图1是本次修改目标；其余输入仅作为角色身份或材质参考。
只修改：[明确一个目标]。
保持不变：画幅、主要动作方向、技能对象、角色身份、服装与饰物、其他区域。
必须保留：银白长发、紫瞳、节纹银角、淡紫翼膜与银白叠鳞尾中实际入镜的特征。
发饰固定在角色自身左侧，不因构图变化而换边。
输出一张独立插画，保持原有4:3比例，无文字、数字、卡框、水印和新人物。
不要顺带添加新的技能效果。
```

## 2. 01银尾打击：突出扫击

参考 `assets/cards/common-v1/01_StrikeIronclad.png`。

```text
只强化这张卡的龙尾扫击构图。主角是一条银白叠鳞龙尾，尾尖沿清楚的横向弧线扫过石靶。
尾部占主要画面，扫击起点、运动轨迹、命中点一眼可见。
减少漂浮石屑和泛光，保留少量紫白速度痕迹；鳞片依然有银白材质细节。
不出现人物脸、胸像或身体，不把龙尾改成剑、鞭子或毛绒尾。
保留4:3画幅，无文字和卡框。
```

## 3. 02龙爪破绽：玉手与龙爪虚影

参考 `assets/cards/common-v1/02_Bash.png`，必要时附人物脸部图解释身份，但明确只做局部。

```text
把人物露出范围缩小为白皙纤手、少量白袖和边缘银发，不出现完整上半身。
一只成年女性人手呈抓握中的爪状，五指解剖关系正确，手指细长自然。
手上方浮现一个更大的半透明紫白龙爪虚影，与真实手分开可辨；不是直接把手变成怪兽爪。
龙爪抓过深色甲片，留下三道清晰裂痕，集中表达撕开防线。
减弱遮挡手指的强光与碎屑，保留银白与淡紫配色、4:3画幅。
不生成第二个人，不画额外手指，不添加文字、卡框或技能说明。
```

## 4. 降低泛光，改善小卡图辨识

```text
只调整光效与细节密度，不改变人物、道具、动作和画面内容。
减少紫白泛光、悬浮碎屑和过细符文，让主体轮廓与背景有明确的明度分离。
保留能量方向、尾尖／手指／盾边等关键轮廓，使缩小为卡牌插画时也能辨认。
银白部分保留中间灰阶，不要整片过曝；不要把银白材质整体染成紫色。
保持原画幅，不生成文字、数字或卡框。
```

## 5. 21鳞纹校准：强调“升级”

参考 `assets/cards/common-v1/21_Armaments.png`。

```text
只改进“校准一张符卡”的叙事关系，保持银白与淡紫材质。
画面中心是一张银鳞符卡，白皙指尖正在修正其中一段暗淡、不规整的纹路，
被修改区域变为清晰、明亮、整齐的纹路，其余区域保持原样。
旁边保留少量防护龙鳞，作为格挡的辅助线索。
不出现人物脸和躯干，不把主体改成新的巨大盾牌，不表现升级所有卡牌。
4:3独立插画，无文字、数字和卡框。
```

## 6. 修正人物一致性

```text
输入图1为修改目标，输入图2—5分别为采用的脸部、正面、左侧、背面参考。
只修正：[发饰侧别／背面散发／龙角节纹／礼服细节，选择一个]。
人物身份、表情、姿势、镜头、光照与其他区域保持不变。
结环发饰及长流苏在角色自身左侧；正面看位于画面右侧，背面看位于画面左侧。
背面保持散发，不改为辫子；保持一对龙翼和一条银白叠鳞尾。
不要重新设计整套服装，不增加新饰物或角色。
```

## 7. 交给编码Agent完成改图接入

```text
在当前独立美术仓库完成一次有范围的素材更新。
目标卡牌：[编号与名称]。
新插画：[仓库相对路径]；本次目标：[一句话说明]。
先阅读README、CONTRIBUTING和docs/STYLE_GUIDE.md。
保留原生插画旧版本，采用新图时只更新对应image路径及实际提示词记录。
不要改卡牌费用、基础效果、标签、数值待核对标记或其他卡牌。
用scripts/build_site.py --render-cards重建完整卡面、总览与网站；非Windows按README指定字体。
查看受影响卡面，核对图片对应关系、文字容纳、手指与人物特征。
提交可评审的文件差异和简短说明；只有明确收到发布或推送指令后才上传。
```

## 8. 比较两个候选，不自动定稿

```text
比较输入的两个同卡牌候选，按这些项目给出具体差异：
缩小后动作辨识度、技能含义、人物露出范围、角色一致性、手部结构、泛光与背景干扰。
指出各自最适合保留的一点和需要修改的一点，引用可见画面，不臆测未展示的细节。
不要仅以“更精致”评价，也不要替用户宣布最终采用。
```
